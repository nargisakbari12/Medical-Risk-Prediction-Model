Medical Risk Prediction Model
This is a small machine learning project I developed to explore how data can be used to predict diabetes risk. My main goal was to build a simple model, work with real-world-style health data, and practice using Python libraries for machine learning.
About the Project:
The dataset contains approximately 100 records. Each record includes information such as age, blood glucose level, insulin level, height, weight, thirst frequency, urination frequency, sugar consumption, number of pregnancies for female individuals, and family history of diabetes.
These features were selected to help the model identify patterns that may be related to diabetes risk.
Tools and Libraries:
I used the following Python libraries:
Pandas: To clean, organize, and prepare the dataset.
 Scikit-learn: To use machine learning models and evaluate their predictions.
Data Cleaning:
Before using the data, I cleaned and organized the dataset to make it more suitable for machine learning.
I corrected typing errors and removed names because they were not useful for prediction. I also excluded blood pressure from the model’s input features because I did not use it in this version of the project.
These steps helped me prepare the dataset and focus on the features selected for the model.
Offline Functionality:
I modified the code so that the project can run offline. This makes it possible to use the model without needing a continuous internet connection, provided that the required Python libraries and files are already available on the device.
This project is for educational purposes only. It is a small experimental model trained on a limited dataset and has not been clinically validated. Its predictions may be inaccurate and should not be used to diagnose diabetes or make medical decisions. Anyone concerned about their health should consult a qualified healthcare professional.
